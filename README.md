
# 🍎 iSTUDIO – Premium iPhone Store

iSTUDIO is a modern, responsive iPhone and accessories e-commerce website built using React, Vite, and Tailwind CSS. It features a premium Apple-inspired design, smooth animations, product browsing, shopping cart, and checkout experience.

## ✨ Features

- Premium Apple-inspired UI
- Cinematic iPhone intro animation
- Responsive navigation bar
- Home page with attractive hero section
- iPhone product listing
- Product details with images, colors, and storage options
- Accessories collection
- Special offers section
- Add to Cart functionality
- Shopping cart with quantity management
- Automatic price calculation
- Checkout page
- Contact page
- Animated page transitions
- Smooth scroll-to-top navigation
- Responsive design for mobile, tablet, and desktop
- LocalStorage cart persistence

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- CSS3
- React Router DOM
- Framer Motion
- Lucide React
- React Icons
- LocalStorage
